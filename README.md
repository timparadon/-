# Military Life · เส้นทางเกียรติยศ

เกมเว็บภาษาไทยแบบผู้เล่นคนเดียว เริ่มเป็นพลทหารอายุ 18 ปี เลือกเหล่า ฝึกสมรรถภาพ ยุทธวิธี และภาวะผู้นำ ทำภารกิจช่วยเหลือประชาชน สะสมประสบการณ์เพื่อเลื่อนยศ และรับเครื่องหมายพิเศษ เมื่อมียศสูงขึ้นสามารถสั่งทหารที่มียศต่ำกว่าได้

## เริ่มใช้งาน

ต้องมี Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง dependencies

```sh
npm start
```

เปิดเว็บผ่านพอร์ต 3000 ตั้งค่า `PORT` เพื่อใช้พอร์ตอื่น ความก้าวหน้าบันทึกใน localStorage ของเบราว์เซอร์ มีปุ่มเริ่มเกมใหม่เพื่อล้างความก้าวหน้า

```sh
npm test
```

ทุกกิจกรรมใช้หนึ่งสัปดาห์ อายุเพิ่มทุก 52 สัปดาห์ กฎยศ เหล่า และเครื่องหมายเป็นระบบสมมติสำหรับต้นแบบ ไม่ใช่เกณฑ์ทางทหารจริง ไม่มีระบบบัญชีหรือ multiplayer ฟอนต์ภายนอกเป็นตัวเลือก หากโหลดไม่ได้จะใช้ฟอนต์ระบบ

## ทำเนียบและการบังคับบัญชา

มี 16 ยศ ตั้งแต่พลทหารถึงพลเอก และ 9 เครื่องหมาย ปลดล็อกด้วยทักษะ จำนวนภารกิจ หรือจำนวนครั้งที่สั่งการสำเร็จ ทำเนียบยศแสดงเกณฑ์ประสบการณ์แต่ละขั้น ทำเนียบกำลังพลประกอบด้วย NPC 16 นายและผู้เล่น ค้นหาด้วยชื่อ ยศ หรือเหล่า และกรองเฉพาะผู้ใต้บังคับบัญชาได้

เลือกปุ่มสั่งการข้างชื่อเพื่อเลือกผู้รับคำสั่ง มี 7 คำสั่งที่ปลดล็อกตามยศ ใช้กำลัง 10 และเวลา 1 สัปดาห์ต่อคำสั่ง ผลสำเร็จทันทีและแสดงงานล่าสุดในทำเนียบ เซฟเดิมเล่นต่อได้โดยไม่ต้องเริ่มเกมใหม่
